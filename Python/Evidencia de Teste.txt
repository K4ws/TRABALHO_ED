Relatório de Testes de Estresse: Código Refatorado vs. Código InicialEste relatório apresenta o confronto direto entre o código inicial (gerado na primeira iteração pela IA) e o código refatorado em Python, demonstrando como a refatoração supera a versão ingênua em estabilidade, consumo de memória e segurança de execução.1. Teste de Estresse: Transbordo de Capacidade (Overflow)Código Inicial: Como utilizava uma lista nativa do Python e o método append(), o código permitia continuar inserindo elementos infinitamente caso a verificação de limite falhasse ou fosse contornada, expandindo a lista dinamicamente no heap.Código Refatorado: Aloca um tamanho estático fixo no módulo array desde a inicialização. Ao tentar estourar a capacidade física de memória reservada, o ponteiro de controle impede a escrita e dispara a exceção PilhaCheiaErro.Resultado: O código refatorado garante impreterivelmente o limite estático de capacidade física, enquanto o inicial sofria de alocação dinâmica indevida.2. Teste de Estresse: Subflutuação de Memória (Underflow)Código Inicial: Ao chamar pop() em uma pilha vazia ou tentar acessar índices negativos (self.dados[-1]) durante o método troca(), o código lançava exceções genéricas nativas do Python (IndexError), sem controle estruturado sobre o estado interno da pilha.Código Refatorado: O estado é controlado pela variável quantidade. Tentativas de remover elementos com a pilha vazia ou executar a operação troca() com menos de 2 elementos são interceptadas antes do acesso ao vetor, disparando a exceção padronizada PilhaVaziaErro.Resultado: O código refatorado impede falhas de runtime nativas e evita que a pilha fique em estado inconsistente.3. Teste de Estresse: Injeção de Tipos IncompatíveisCódigo Inicial: Por usar uma lista heterogênea comum ([]), a pilha aceitava misturar múltiplos tipos de dados na mesma instância (por exemplo, empilhar um float ou uma str longa dentro de uma pilha criada para inteiros).Código Refatorado: A estrutura física aceita apenas o typecode configurado ('q', 'd' ou 'u'). Além disso, o método de inserção valida estritamente a entrada (exigindo que caracteres str possuam tamanho exatamente igual a 1).Resultado: O código refatorado rejeita imediatamente qualquer tipo incompatível com a exceção TipoErro, preservando a integridade da memória.4. Teste de Estresse: Desempenho e Complexidade de Operações (LIFO)Código Inicial: O uso recorrente de .append() e .pop() em listas dinâmicas provoca operações frequentes de realocação de memória no sistema operacional quando a lista precisa redimensionar o seu buffer interno.Código Refatorado: Como a memória física é alocada inteiramente de uma só vez no __init__, a inserção e remoção no topo através do ponteiro self.quantidade executa em tempo estritamente constante $O(1)$ sem nenhuma sobrecarga de realocação de memória.Resultado: O código refatorado elimina a variabilidade de tempo de execução e garante complexidade de espaço fixa $O(1)$.
